How to make the token (one minute, once)
  1. Open github.com/settings/personal-access-tokens/new
  2. Name it anything. Set Expiration to whatever you are comfortable with.
  3. Repository access → Only select repositories → INSVRC
  4. Permissions → Repository permissions → Contents: Read and write
  5. Optional, for the "Re-check names now" button: also Actions: Read and write
  6. Generate, copy, paste it above, press Connect.

Scoped this way the token can only read and write files in INSVRC. It cannot touch your other repos, your account settings, or anything else. If it ever leaks, revoke it on that same settings page and make a new one. I can't create or handle the token for you — it has to be yours.

This page is public, but it does nothing without your own token. Source file: sources/global_blacklist.src · the published list rebuilds about a minute after each commit, and every id is re-read every 3 hours to catch renames.
