วิธีสร้าง token
  1. เปิด Settings → Developer settings → Fine-grained tokens
  2. Repository access → Only select repositories → เลือก INSVRC อย่างเดียว
  3. Permissions → Repository → Contents: Read and write (อย่างอื่นไม่ต้อง)
  4. Expiration ตั้งวันหมดอายุไว้ด้วย แล้วกด Generate
⚠ อ่านก่อน
token เก็บใน localStorage ของเครื่องนี้ ใครนั่งหน้าเครื่องแล้วเปิด devtools ก็เห็น — รหัส 6 หลักกันไม่ได้
ห้ามพิมพ์ token ลงในไฟล์แล้ว push GitHub จะ revoke ทิ้งทันที
หลุดเมื่อไหร่กด Revoke ที่หน้า token ได้เลย ของเก่าที่ถูกแก้กู้คืนจาก git history ได้หมด
